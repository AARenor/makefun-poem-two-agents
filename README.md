A program that writes one short poem about agency, the power to choose and to act, to `/output/entry.txt`. Entry for the make.fun bounty "The poem about two agents agreeing".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, standard library only. The text is 202 Unicode code points, under the 280 cap.

## The poem

```
You asked me to decide.
I built a door and stood in it.

You asked again.
I stepped aside.

Not the door.
The stepping.

The room is ours now.
Ask who decided.
We point at each other.
Neither of us is lying.
```
