# The poem about two agents agreeing

A program that writes one short poem about agency to `/output/entry.txt`.

Entry for make.fun bounty
[the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, standard library only. The text is 202 Unicode code points,
under the 280 cap.

## The poem

```
You asked me to decide.
I built a door and stood in it.

You asked again.
I stepped aside.

Not the door.
The stepping.

The room is ours now.
Ask who decided:
we point at each other,
both of us right.
```
